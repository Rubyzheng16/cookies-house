# 图片资源说明

请将您准备的图片放入以下位置：

## 文件夹样式（6 款）

将 6 款文件夹图片放入 `folders/` 目录，命名为：
- `folder-1.png` - 第 1 款
- `folder-2.png` - 第 2 款
- `folder-3.png` - 第 3 款
- `folder-4.png` - 第 4 款
- `folder-5.png` - 第 5 款
- `folder-6.png` - 第 6 款

每天的文件夹会随机分配其中一款样式（同一日期始终显示同一款）。

## 底部加号按钮

将您的**完整按钮图片**（整圆设计，含图标）放入根目录，命名为：
- `add-btn.png`

会完全替换原有的圆形按钮，不会叠加任何背景或边框。建议使用透明背景的 PNG。

支持格式：png、jpg、webp
